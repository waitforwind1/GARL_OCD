# GARL-OCD

本文仓库对应论文：

**《结构相似性校准注意力与锚定隶属传播的重叠社区发现》**
*Overlapping Community Detection with Structural-Similarity-Calibrated Attention and Anchored Membership Propagation*

## 模型介绍

GARL-OCD 是一种面向属性网络的无监督重叠社区发现模型。

该模型融合节点属性、稀疏邻接信息和局部拓扑统计量，并通过结构相似性校准注意力与锚定隶属传播机制，提高模型对重叠社区及模糊社区边界的识别能力。

论文实验在 6 个 Facebook ego-network 子图和 2 个 Microsoft Academic Graph（MAG）学术合作网络上进行。

## 方法概述

GARL-OCD 主要包括以下几个部分：

1. **结构增强输入**

   联合使用节点属性、稀疏邻接行以及局部拓扑统计量，对节点语义、直接连接模式和局部结构角色进行统一描述。

2. **结构相似性校准注意力**

   在图注意力机制的基础上引入结构相似性与表示相似性，对邻居聚合权重进行校准。

3. **锚定隶属传播**

   以编码器产生的初始社区隶属预测作为锚点，进行受控的局部一致性修正。

4. **无监督图重构**

   采用 Bernoulli–Poisson（BerPo）解码方式，通过图结构重构学习非负连续社区隶属表示。

## 参数选择说明

为避免根据真实网络标签反复调整超参数，GARL-OCD 的关键参数首先在独立 LFR 开发集上进行一次性选择。

最终确定的参数在进入 8 个真实网络实验前被冻结，不再根据单个真实数据集的结果重新选择。

真实网络中的社区标签不参与模型训练、梯度更新、早停或逐数据集参数选择。
